# Yugatn Neo Skills — предложение пилота для технологического партнёра

Статус: проект плана (4 ноября 2026 года), не одобренное исследование и не запущенный пилот.

## Цель и узкая область MVP
Проверить, улучшает ли безопасный голосовой ИИ-наставник выполнение **трёх–пяти низкорисковых вводных упражнений** по сравнению с теми же инструкциями без диалога. Не оценивать лечение, спортивное мастерство или сложные боевые техники.

В коде уже есть локальные колёса, журнал, урок с таймером и подбор вводных занятий. **Нет** подтверждённой сборки Xcode на реальном устройстве, валидированного определения поз или готового голосового тренера.

## План работ и границы
1. Подтвердить iOS-сборку, работу офлайн и XCTest, проверить восстановление данных и кнопки остановки.
2. Проверить методику упражнений с преподавателем и специалистом по безопасности; утвердить доступный формат инструкций.
3. Добавить опционального голосового ИИ-наставника на Yandex AI Studio / SpeechKit с явной маркировкой рекомендаций как подсказок, а не медицинских назначений.
4. Изучить on-device определение положения тела как **эксперимент**; первое ограничение — видимость человека в кадре и отказ от оценки при неуверенности. Не заявлять, что одна камера доказывает правильность техники.
5. По согласованному с экспертами и при необходимости этическому протоколу сравнить две группы добровольных совершеннолетних пользователей с одинаковыми уроками (инструкции и инструкции + ИИ); отдельная группа детей требует отдельной проверки.

## Измеряемые исходы
- Доля завершённых сессий, добровольные остановки и нежелательные события.
- Освоение заранее определённых безопасных элементов, оценённое независимым инструктором без знания группы.
- Частота неверных/опасных рекомендаций ИИ, доля отказов при низкой уверенности камеры.
- Удобство, доступность и время отклика; стоимость сессии для инфраструктуры.
- Отчёт с ограничениями выборки и неопределённостью, без маркетингового утверждения об эффективности до результатов.

## Неподвижные ограничения
При боли или головокружении прекращать тренировку и не рекомендовать нагрузку. Камера, микрофон, HealthKit и облачная обработка требуют отдельного разрешения; видео не сохраняется и не отправляется по умолчанию. Базовый локальный режим не зависит от API и доступен без аккаунта.

## Критерий передачи пилота партнёру
Сборка и тесты подтверждены логами, есть экспертно утверждённые уроки, документированная модель угроз, протокол измерений, возможность удаления данных и описание всех ограничений. Результаты и интеллектуальные права на новые компоненты оформляются отдельным соглашением.
