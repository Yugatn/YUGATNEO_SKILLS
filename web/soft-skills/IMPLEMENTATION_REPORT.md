## Требует согласования или дальнейшей работы

- Авторское и экспертное одобрение содержания 60 карточек; независимая проверка научных формулировок и возрастной применимости.
- Упражнения для оставшихся 35 тем.
- Самостоятельные тексты для четырёх возрастных маршрутов: сейчас исходные общие шаги сопровождаются возрастной методикой.
- Специфические критерии для карточек с общими формулировками; два конкретных предложения представлены отдельно.
- Процедура проверки устойчивого переноса навыка. Текущая отметка «закреплено» — самоотчёт участника.

Код подготовлен к техническому рассмотрению. Это не утверждение пособия, не клиническая валидация и не доказательство эффективности упражнений.
