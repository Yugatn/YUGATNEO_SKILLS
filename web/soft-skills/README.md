# Тренажёр гибких навыков · MVP 0.2

Отдельный веб-модуль проекта Yugatn Neo Skills. Рабочая архитектура, не утверждённый учебник и не психотерапевтическая программа. Работает в современном браузере без сервера данных, API-ключей и сборщика; подключение к SwiftUI не выполнено.

Источник: [архитектура в Notion](https://app.notion.com/p/412d132385998128a5abdc0f38a911c3). Снимок получен 16.11.2026. Каталог содержит ровно **95 тем: 35 тем оглавления и 60 карточек с упражнениями**. Не все темы являются готовыми уроками.

## Запуск

Из корня репозитория:

```sh
cd web/soft-skills
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Не открывайте index.html через file://: браузер может блокировать загрузку JSON. Статические файлы можно размещать на HTTPS-хостинге без сборки. Публичное развёртывание в эту задачу не входит.

## Что работает

- Выбор возраста 4–6, 7–11, **12–17**, 18+, раздела и навыка; поиск; каталог 95 тем.
- Детская/взрослая ситуация, механизм, исходная общая возрастная методика.
- Пошаговое прохождение, возврат, добровольные ответы, критерий и сброс.
- Независимые статусы прохождения: «не начато / в процессе / закреплено».
- Редакционная маркировка: «на проверке / согласовано / не подтверждено». Ни один материал автоматически не согласован.
- Сохранение только прогресса по явному включению; по умолчанию память вкладки. Ключ включает версию материала и возраст. Полная очистка относится только к этому модулю.
- Новые редакционные идеи вынесены в [PROPOSALS.md](PROPOSALS.md), а не в исходный текст.

## Модель и сохранность содержания

[types.d.ts](types.d.ts) описывает Skill, Progress и Catalogue; [model.mjs](model.mjs) содержит переходы состояния. `data/skills.json` — нормализованные карточки. `data/source-snapshot.json` — исходные извлечённые страницы 02–13 и точные фрагменты оглавления/возрастной таблицы основной страницы. Это снимок возвращённого Notion текста, не полный экспорт всей книги.

Каждая карточка содержит URL, заголовок, дословный фрагмент и SHA-256. Изменяется только машинное представление: удаляются маркеры нумерации шагов, унифицируются ID (06.1 → 06.01). Формулировки не переписываются. Пустые элементы 35 тем заданы null/пустыми массивами; запуск для них заблокирован. Источник Notion не изменяется и автоматически не синхронизируется.

Возрастной выбор использует исходную таблицу, общую инструкцию раздела и детскую/взрослую ситуацию. Шаги общие: индивидуальные возрастные сценарии требуют разработки и согласования. Научные формулировки перенесены как рабочий материал, их независимая проверка не проводилась.

## Приватность и ограничения

Нет аналитики, сетевой отправки ответов, аккаунтов, ИИ-диагностики и рейтингов. Страница загружает собственные статические файлы; внешние ссылки открываются только по нажатию. По умолчанию всё исчезает при перезагрузке вкладки. Если включено сохранение, шаги и статусы остаются в localStorage профиля браузера, доступны другим пользователям того же профиля и не шифруются. Ответы на вопросы никогда не входят в сохраняемую структуру. Между разными устройствами синхронизации нет. Изменение сохранения в другой вкладке приостанавливает автосохранение текущей; можно явно загрузить сохранённые данные или экспортировать текущую вкладку. Удаление сохранения очищает другие открытые вкладки. Перед записью также проверяется, не изменилось ли сохранение. Это защита от обычного конфликта вкладок, а не транзакционная синхронизация: строго одновременная запись не блокируется. На общем устройстве отключайте сохранение и очищайте прогресс.

Изменение материала создаёт новый ключ прогресса; старый прогресс не засчитывается автоматически. Повреждённые или недоступные данные вызывают понятное сообщение, приложение продолжает работать в памяти. Авторское согласование выполняется только явным редакционным изменением данных с подтверждающими полями, не пользователем тренажёра.

## Проверки

Node.js 20+; сторонние зависимости для тестов модели не нужны:

```sh
npm run build:data
npm test
```

Тесты проверяют полноту каталога, дословное соответствие источнику, условия статусов, разделение возрастов/версий, сброс и повреждённое хранилище. `tests/browser.cjs` — отдельный сценарий Chromium/Playwright; инструкции запуска находятся в начале файла. Результаты фактического прогона: [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md).

## Резервные копии · 0.2

Кнопка «Скачать прогресс JSON» выгружает только нормализованные шаги, статусы и возрастные маршруты текущих версий. Личные ответы, авторское согласование и тексты пособия не включаются. Файл не зашифрован: храните его приватно.

Импорт ограничен 512 КБ, проверяет приложение и версию формата, показывает количество совместимых/пропущенных записей и совпадений. Применение — отдельная кнопка; отмена ничего не меняет. По умолчанию существующие записи выигрывают конфликт. Явная замена требует подтверждения. Записи устаревших уроков не засчитываются новой версии. Импорт не включает сохранение автоматически и не может согласовать материал. Ответы в текущей вкладке при применении импорта очищаются.

Новые тесты покрывают вредоносные/повреждённые файлы, фильтрацию полей, конфликты, предпросмотр, отмену, замену и удаление в нескольких вкладках. Содержание всех 95 тем осталось прежним.
